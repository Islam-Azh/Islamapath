# Teacher & Student English — запуск с Supabase

Сайт для двоих: ученик (Islam) и учитель (Айнура). Данные, домашка, тексты и аудиозаписи хранятся в Supabase и видны обоим с любых устройств.

| Файл | Что это |

| `program.js` | XP, ранги, ачивки, программа курса (Files 1–12) |
| `hub.js` | Меню: Learn · Progress · More |

**Как обновляется сайт:** код лежит в GitHub (Islam-Azh/Islamapath). Любое изменение там за минуту само появляется на https://islamapath.netlify.app. Перетаскивать папку в Netlify больше не нужно.

Пока `config.js` пустой, сайт работает в демо-режиме: всё хранится в одном браузере, вход по кнопке «I'm the student / teacher».

**Важно:** если открыть `index.html` двойным щелчком (адрес начинается с `file://`), браузер не даст загрузить папку `data/`, и на странице Materials будет предупреждение. Это нормально: на Netlify всё загружается.

## Шаг 1. Создать проект Supabase (5 минут)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатный тариф).
2. **New project** → название, например `ts-english`, придумайте пароль базы (сохраните его), регион — ближайший (Frankfurt подойдёт).
3. Дождитесь, пока проект создастся.

## Шаг 2. Создать таблицы и права

1. В проекте откройте **SQL Editor** → **New query**.
2. Вставьте всё содержимое `supabase-setup.sql` и нажмите **Run**. Должно быть «Success. No rows returned».

Что создаётся:
- `profiles` — кто ученик, а кто учитель;
- `app_state` — данные сайта (домашка, карточки, тесты, проверки…), одна строка на раздел;
- личные заметки учителя хранятся отдельно, и ученик их не может прочитать даже теоретически (Row Level Security);
- приватное хранилище `audio` для устных ответов и голосовых комментариев.

## Шаг 3. Создать два аккаунта и закрыть регистрацию

1. **Authentication → Users → Add user → Create new user**. Введите свой e-mail и пароль, включите **Auto Confirm User**. Повторите для Айнуры.
2. Вернитесь в **SQL Editor**, в конце `supabase-setup.sql` есть закомментированный блок «4». Скопируйте его в новый запрос, уберите `--` в начале строк, подставьте реальные e-mail и выполните.
3. Проверка — запрос из той же секции должен вернуть две строки: `student · Islam` и `teacher · Айнура`.
4. **Authentication → Sign In / Providers** (в некоторых версиях **Settings**) → выключите **Allow new users to sign up**. Так никто посторонний не сможет создать аккаунт.

## Шаг 4. Заполнить `config.js`

1. В Supabase откройте **Project Settings → API** (или кнопку **Connect** вверху).
2. Скопируйте **Project URL** и ключ **anon public**.
3. Вставьте их в `config.js`:

```js
window.TS_CONFIG = {
  supabaseUrl: 'https://xxxxxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...'
};
```

Ключ `anon` можно держать в открытом файле — он для этого предназначен. Данные защищены правами из шага 2. **Никогда** не вставляйте сюда ключ `service_role`.

## Шаг 5. Выложить сайт в интернет

Сайт связан с репозиторием GitHub **Islam-Azh/Islamapath**: Netlify сам публикует каждое изменение (Project configuration → Build & deploy → Continuous deployment). Build command и Publish directory пустые.

Подойдут и другие бесплатные хостинги статических сайтов (GitHub Pages, Cloudflare Pages, Vercel). Важно только, чтобы сайт открывался по `https://` — иначе браузер не даст доступ к микрофону.

## Как это работает

- **Вход** — по e-mail и паролю. Роль (ученик или учитель) берётся из таблицы `profiles`, а не выбирается кнопкой.
- **Синхронизация** — изменения сохраняются через ~1 секунду. Значок в шапке: ☁️ сохранено, ⏳ сохраняется, ⚠️ нет связи (сайт повторит попытку сам).
- **Живые обновления** — если Айнура задала домашку, у вас она появится без перезагрузки страницы. Если вы в этот момент что-то печатаете, обновление подождёт, пока вы выйдете из поля.
- **Расписание** — в **Settings → Lesson schedule** учитель указывает день и время урока. Новая домашка по умолчанию получает срок «к следующему уроку», а на главной видна дата следующего занятия.
- **Аудио** — записи загружаются в Supabase Storage и доступны второму участнику на любом устройстве.
- **Тема, подсказки на русском, скорость аудио** — сохраняются только на текущем устройстве.
- **Резервная копия** — **Settings → Export backup (JSON)**. Учитель может восстановить её через **Import backup**. Так же можно перенести данные из демо-режима в Supabase.

## Что важно знать

- **Бесплатный проект Supabase засыпает** после примерно недели без активности. Если сайт перестал входить, откройте проект в панели Supabase и нажмите **Restore**. При регулярных занятиях этого обычно не случается.
- **Одновременное редактирование** одного и того же раздела в одну секунду (например, оба пишут в чат одной домашки) может привести к тому, что сохранится последнее изменение. Для двух человек это редкость.
- **iPhone:** запись голоса работает в Safari, но автоматическая расшифровка речи там нестабильна — текст можно поправить вручную перед отправкой.
- **Учебник:** номера страниц и названия уроков в карте курса — заготовки. Айнура может сверить их со своим изданием в **Course editor**.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Вместо формы входа видны кнопки «I'm the student / teacher» | `config.js` пустой или не загрузился (он должен лежать рядом с `index.html`) |
| «Wrong e-mail or password» | Пароль пользователя в **Authentication → Users**; у пользователя включён Auto Confirm |
| «This account has no role yet» | Не выполнен блок «4» из `supabase-setup.sql` для этого e-mail |
| Значок ⚠️ не исчезает | Интернет, не спит ли проект Supabase |
| Учитель не слышит запись | Запись была сделана в демо-режиме до подключения Supabase — такие файлы остаются в том браузере |
